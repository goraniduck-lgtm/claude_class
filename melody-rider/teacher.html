학급에서 함께 들을 음악 파일을 선택하면 곡 목록 + 음악 파일을 하나의 ZIP으로 만들어 드려요. 학생들이 파일을 따로 받을 필요가 없습니다.

1. 감상곡 파일 추가

아직 추가한 감상곡이 없어요.

원하는 감상곡을 추가해 주세요.

2. 학생들이 듣게 하는 방법

  1. 위에서 파일을 고르고 곡 제목과 설명을 수정한 다음 음악 배포용 ZIP 만들기를 누릅니다.
  2. ZIP을 압축 해제하면 music-library.json과 music/ 폴더가 생깁니다.
  3. 학생용 index.html이 있는 GitHub Pages 사이트의 같은 폴더에 music-library.json을 넣고, music/ 폴더도 그대로 올립니다. 기존 파일은 교체합니다.
  4. 학생들이 웹 주소를 다시 열면 기본 체험곡 3곡 아래에 선생님이 등록한 곡이 나타납니다.

이 화면에서 추가한 곡은 곧바로 학생에게 전송되지 않아요. 배포한 사이트의 파일을 실제로 갱신해야 공유됩니다. 음악 파일은 반드시 학교 수업에서 배포·스트리밍해도 되는 권리가 있는 파일을 사용해 주세요. 유튜브 페이지 주소는 MP3 음원 주소가 아니므로 여기에 등록할 수 없습니다.
