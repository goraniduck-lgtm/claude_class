# 다각형 다리 작전 — 개발 명세 v1.4 (24단계)

작성일: 2026-11-22 · 확장 업데이트 2026-11-23

## 목적
구슬을 출발점에서 도착점까지 옮기는 과정에서 4학년 수학의 도형 성질을 장치 작동에 활용한다. 맵의 경사, 틈, 착지 높이, 통로 모양을 관찰하고 경로와 출발 속도를 결정한다.

웹사이트: https://goraniduck-lgtm.github.io/claude_class/polygon-bridge/

## 확정된 사용자 요구
1. 새 장치는 매치3 게임의 새 타일처럼 **처음 한 번 설명**하고 이후에는 별도 설명 없이 자연스럽게 재등장.
2. 평행·직각·정다각형·대각선 장치마다 **고유 시각 요소와 체결/가동 애니메이션**.
3. 초기 화면에 수학 조건을 미리 노출해 발견의 의미를 없애지 않는다. (최초 학습 장치 안내는 예외)
4. **공이 움직이는 도중에도 즉시 중단·수정·재도전** 가능.
5. 최소 정보로 화면을 구성하며, 태블릿 가로 화면 사용과 링크 접속을 기본으로 함.
6. **교육적 정합성**: 도형을 단순히 교체해도 물리 결과가 같다면 충분한 학습 게임이 아니므로 기하학적 조건 검증이 게임 기계에 실질적으로 작용해야 함.

## 장치 사전

| 코드 | 장치 | 수학적 조건 | 고유 반응 |
| --- | --- | --- | --- |
| P | 평행 잠금장치 ∥ | 사각형의 마주 보는 두 변이 평행 | 양쪽 기계팔 체결, 초록 전류 |
| R | 직각 연결기 ∟ | 한 꼭짓점에서 만나는 두 변이 직각 | ㄱ자 힌지가 정확히 맞물림 |
| E | 정삼각형 열쇠 △ | 세 변의 길이가 같음 | 금빛 삼각 열쇠 활성화 |
| D | 대각선 발전기 ✧ | 오각형의 서로 이웃하지 않은 꼭짓점을 잇는 고유 대각선 5개 | 에너지 선 충전 및 가동 |

장치 작동 조건은 **가상 게임 규칙**이다. 실제 다리가 반드시 특정 도형이어야 안전하다고 가르치면 안 된다.

## 챕터 1 — 구현된 스테이지 8개
| 단계 | 표면 미션 | 모듈 | 학습 역할 |
| --- | --- | --- | --- |
| 1 | 첫 번째 잠금 | P | 최초 장치 소개 |
| 2 | 낮은 착지대 | 장치 없음 · 출발 속도 | 같은 낙하 시간에 속도가 다르면 수평 이동 거리가 달라짐 |
| 3 | 꺾인 연결기 | R | 최초 장치 소개 |
| 4 | 두 단계 잠금 | P → R | 순차 복합 |
| 5 | 빛나는 열쇠 | E | 최초 장치 소개 |
| 6 | 교차 관문 | R → E | 순차 복합 |
| 7 | 별빛 발전기 | D | 최초 장치 소개 |
| 8 | 마지막 동력실 | P → R → E → D | 종합 복합 + 챕터 확인 |

**챕터 1에 한정:** 이 챕터의 복합 스테이지는 장치를 순서대로 해결한 뒤 다음 모듈로 바꾸는 체크포인트 방식이다. 챕터 3에서는 독립 도형들을 한 화면에서 동시에 조작하는 방식이 도입된다.

## 챕터 2 — 신규 스테이지 9~16

| 단계 | 표면 미션 | 실제 메커니즘 | 학습 목적 |
| --- | --- | --- | --- |
| 9 | 두 개의 표시등 | 동일한 사각형에서 평행+직각 동시 조건 | 두 성질을 함께 만족 |
| 10 | 돌아온 열쇠 | 정삼각형 → 오각형 대각선 | 기존 개념 재사용 |
| 11 | 마름모 톱니 | 네 변 길이가 같은 마름모 | 새 장치 첫 학습 |
| 12 | 연결된 톱니 | 정삼각형 → 마름모 | 기존·신규 조합 |
| 13 | 정사각형 방패 | 네 변 같음 + 네 각 직각 | 새 장치 첫 학습 |
| 14 | 회전하는 방패 | 정사각형 → 직각 연결기 | 성질 재적용 |
| 15 | 혼합 회로 | 평행+직각(동시) → 정삼각형 → 마름모 | 동시 및 순차 조합 |
| 16 | 챕터 2 동력실 | 평행+직각(동시) → 마름모 → 정사각형 → 대각선 | 종합 퍼즐, 챕터 2 확인 |

### 신규 장치 세부 규칙

- **평행+직각 복합 잠금 (기호 ∥∟)**: 동일한 사각형의 윗변/아랫변 평행과 왼쪽 위 꼭짓점의 직각을 **동시에** 판정. 한쪽 조건만 만족하면 한쪽 표시등만 초록색이며 물리 다리는 열리지 않음.
- **마름모 톱니 (◇)**: 윗변의 두 꼭짓점을 고정하고, 한 꼭짓점을 조정하면 네 번째 점이 자동으로 대응하여 평행사변형을 구성. 인접한 변의 길이까지 같아지면 네 변이 같다는 성질을 충족. 정사각형도 마름모의 범주에 포함한다.
- **정사각형 방패 (□)**: 동일한 생성 방식으로 평행사변형을 만든 뒤, 인접한 변의 길이가 같고 한 각이 직각일 때 작동. 사각형의 다른 각도 직각이 되어 정사각형을 구성.
- 새 장치만 처음 한 번 설명. 반복 시 기호·색상·작동 애니메이션만 표시.
- 새 장치의 조건은 교과 개념과 별도로 판정하며, 물리 시뮬레이션에서 다리 고정 여부를 결정.
- 챕터 2 마지막에 정사각형·마름모·복합 조건 관련 4문항 확인. 게임 중 매 스테이지 정답 문제는 생략.

**챕터 2의 복합 방식:** 9, 15, 16단계에서는 **한 도형에 두 조건을 동시에 만족시키는 퍼즐**을 구현했다. 다른 복합 단계는 장치를 하나씩 켜는 순차 체크포인트 방식이며, 독립 도형의 동시 조작은 챕터 3에서 구현했다.


## 챕터 3 — 17~20단계 (독립 도형 동시 조작)

| 단계 | 미션 | 같은 장면에 놓인 독립 도형 | 완료 조건 |
| --- | --- | --- | --- |
| 17 | 쌍둥이 장치 | 왼쪽 평행 사각형 + 오른쪽 직각 사각형 | 두 잠금 모두 활성화 |
| 18 | 두 갈래 협곡 | 마름모 또는 정사각형 | 위층 다리와 아래층 관문 중 하나를 고르고 해당 장치만 작동 |
| 19 | 이어지는 에너지 | 마름모 + 정삼각형 | 톱니와 열쇠로 굽은 다리 연결 |
| 20 | 챕터 3 동력실 | 정삼각형 + 직각 사각형 + 정사각형 | 세 장치 모두 동작 + 챕터 3 확인 |

### 구현 구조와 차별점

- 한 장면에 2~3개의 **서로 독립된 도형**을 배치한다. 각 도형의 노란 꼭짓점을 직접 조작할 수 있다.
- 도형별 위치, 꼭짓점, 기하 판정, 조건 상태, 잠금 효과는 독립적으로 계산한다.
- 장치는 고유 실루엣과 색을 유지한다. 작동하면 몸체가 밝아지고 상단 아이콘 밑줄로 상태를 표시한다.
- 17·19·20단계는 모든 도형이 조건을 만족해야 다리가 연결된다. 18단계는 선택한 길과 연결된 장치 하나만 사용한다.
- 이 모드에는 순차 진행 버튼이 없으며, 미완성 도형으로 언제든 돌아가 수정할 수 있다.
- 새 수학 장치를 추가하지 않는다. 이미 한 번 익힌 기호(∥, ∟, △, ◇, □)와 효과를 재활용하여 설명 없이 풀이하게 한다.
- 20단계 통과 후 챕터 3 확인 문제 4개가 나타난다.
- 모든 기기는 링크 접속이며, 기록은 기기 로컬 저장이다. 기존 16단계 기록은 보존하고 17~20단계 항목을 추가한다.

### 수학 판정

- 동시 조작 기기는 고정된 윗변과 조작 가능한 꼭짓점으로 표현한다.
- 평행: 두 변 벡터의 정규화 외적 절댓값이 기준값보다 작아야 한다.
- 직각: 인접 두 변 벡터의 정규화 내적 절댓값이 기준값보다 작아야 한다.
- 정삼각형: 세 변의 길이 차를 검사한다.
- 마름모: 평행사변형 구조에서 이웃한 두 변의 길이가 같으면 네 변이 같아진다.
- 정사각형: 위 마름모 조건과 함께 인접 두 변이 직각인지 검사한다.
- 주의: 잠금장치의 수학 조건은 게임 속 고유 규칙이며, 실제 모든 다리의 안전성 규칙으로 일반화하면 안 된다.

## 챕터 4 — 21~24단계 (움직이는 길)

| 단계 | 미션 | 도형과 구조물 | 운송 과제 |
| --- | --- | --- | --- |
| 21 | 끊어진 도약로 | 평행 → 접이식 다리 | 다리 뒤 경사로에서 충분히 빠르게 뛰어 건너편 착지대에 닿는다. |
| 22 | 낮은 터널 | 직각 → 회전문 | 문을 지난 후 천천히 낙하해 낮은 터널 아래를 통과한다. 너무 빠르면 터널 입구에 닿는다. |
| 23 | 승강기 환승 | 정삼각형 → 승강기 | 구슬이 발판에 멈춘 뒤 학생이 승강기를 작동시켜 내려 보낸다. |
| 24 | 골짜기 운송로 | 마름모 → 다리, 정사각형 → 승강기 | 도약에 필요한 속도를 미리 정한다. 승강기로 아래쪽 경사로에 내려 마지막 틈을 건넌다. |

## 맵과 장치 표현

- 일반 스테이지의 출발·도착 절벽 위치, 높이, 경사와 굽은 구간을 단계마다 다르게 배치했다. 일반 스테이지에서는 도형을 맞추면 해당 맵의 다리가 이어지고 구슬은 다리의 높이를 따라 굴러간다.
- 2·18·21~24단계에서는 운송 과제를 직접 조작한다. 18단계의 위층과 아래층은 출발 위치를 공유하며, 선택에 따라 다리, 관문, 경사, 도착 높이가 달라진다.
- 평행은 하늘색 평행 막대, 직각은 호박색 ㄱ자, 정삼각형은 보라색 삼각 열쇠, 대각선은 분홍색 오각 별, 마름모는 산호색 겹마름모, 정사각형은 연두색 테두리 방패로 표시한다. 복합 잠금은 평행과 직각 표시를 함께 사용한다. 모양과 기호는 대기·작동 상태 모두에서 유지한다.
- 물리 구조물과 아래 조작부는 같은 번호와 장치 모습을 사용한다. 접이식 다리, 회전문, 승강기는 각각 최초 등장 시 소개한다. 2단계 착지대도 처음 한 번 설명한다.
- 틈에서는 중력을 적용한다. 도약 경사로 끝에서 수평 속도에 비례하는 위쪽 속도를 부여한다. 구슬의 원과 회전문 선분의 접촉 및 낮은 터널 천장과의 접촉을 검사한다. 승강기는 구슬이 정지턱에 도달하면 하강 입력을 기다리고, 발판이 아래층에 닿을 때까지 구슬을 받친다.
- 화면 좌표로 동작하는 수업용 2차원 모형이다. 마찰, 탄성, 하중, 구조물 사이의 충돌과 자유 배치·회전은 모델링하지 않는다.
- 기존 24단계 완료 기록과 이미 본 장치 안내는 그대로 유지한다.

## 화면 구성
- 상단: 챕터 1~4 선택 탭과 **현재 챕터의 번호만** 표시, 현재 미션 한 줄.
- 게임 화면: 공·도형·조작 점·장치 애니메이션, 복합 단계에서 현재/완료 장치 토큰.
- 하단: 처음부터, 단서, 출발, 중단·수정, 즉시 재도전. 속도·경로·승강기 조작은 해당 맵에서만 노출.
- 장치 첫 등장: 기호와 짧은 조건 소개, [직접 해보기]. localStorage로 기기별 최초 1회 노출(기존 sessionStorage 기록도 읽어 이관).
- 구슬 도착: 다음 단계로 자연스럽게 연결. 매 단계 퀴즈 제거. 8·16·20·24단계에서 챕터별 4개 개념 확인.
- 완료 기록: 브라우저 localStorage (계정·중앙 수집 없음).

## 구현 메모
- HTML/CSS/JS 단일 정적 페이지, GitHub Pages 배포.
- Canvas 내부 좌표 1100×560, 공 반지름 16, 중력 1180, 기본 수평속도 255, 속도 선택 맵은 190·280·390. 실험은 일반 맵 7.8초, 운송 맵 9초이며 승강기 조작 대기 시간은 제외한다.
- 평행 판정: 두 변 벡터의 정규화 외적 절댓값 < 0.0025.
- 직각 판정: 두 변 벡터의 정규화 내적 절댓값 < 0.0035.
- 정삼각형: 각 변 길이 차 < 1.8 게임 좌표 단위.
- 오각형 대각선: 서로 이웃하지 않은 두 점의 고유 선분 5개, 중복 제외.
- 물리 판정(구슬 이동)과 수학 판정(장치 활성화)은 분리.
- 상태: 편집, 실험, 실패, 도착. 공이 멈추기 전에도 중단·재도전 가능.

## 현재 검수
- Chrome 1024×768 터치 에뮬레이션에서 전체 스테이지의 꼭짓점 드래그·선택, 실제 Canvas 이동과 도착, 완료 기록 보존, 마지막 개념 확인을 검수했다.
- 2단계의 속도별 도달 여부, 18단계의 두 경로를 각각 도형 하나로 완주하는 것과 닫힌 관문에 닿는 경우, 21단계 도약과 22단계 터널의 반대되는 속도 효과를 확인했다.
- 23단계 발판 대기와 사용자 하강 입력, 이동 중 즉시 중단·재도전, 24단계 승강기에서 경사로로 갈아타는 경로를 확인했다.
- 실제 교실 태블릿의 터치 조작·가독성·동시 접속은 추가 확인이 필요하다.

## 다음 개발 우선순위
- **P0** 실물 Android 태블릿 가로 화면에서 드래그, 버튼 크기, 텍스트 겹침 검수.
- **P0** 새로운 장치의 튜토리얼을 정적인 글보다 **짧은 장치 동작 시범 애니메이션**으로 강화.
- **P1** 구조물끼리의 지지나 충돌을 활용하는 퍼즐 탐색.
- **P1** 마지막의 구슬 도착 완료와 학습 확인 문제 완료를 분리해서 기록.
- **P1** 우연한 드래그보다 도형 성질 이해가 성공에 더 크게 작용하도록 난이도 및 판정 피드백 개선.
- **P2** 필요한 경우 식별정보 없는 학습 진단 지표 추가.

## 스테이지 승인 질문
1. 이 성질을 활용하지 않고 아무 도형으로도 성공할 수 있지 않은가?
2. 학생이 장치의 변화로 규칙을 관찰할 수 있는가?
3. 첫 등장 이후에도 기호와 반응이 일관되어 전이 학습이 가능한가?
4. 실패 시 즉시 중단·재도전 가능한가?
5. 학생이 왜 그 도형이 성공했는지 설명할 수 있는가?
