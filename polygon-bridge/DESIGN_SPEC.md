# 다각형 다리 작전 — 개발 명세 v1.1 (16단계)

작성일: 2026-11-22 · 확장 업데이트 2026-11-22

## 목적
4학년 수학의 도형 성질을 **물리 퍼즐 장치의 실제 활성화 조건**으로 사용한다. 자유로이 그린 선이 단순히 공을 이동시키는 게임이 아니라, 조건의 발견 → 장치 작동 → 재사용 → 복합 문제로 발전하는 게임이다.

웹사이트: https://goraniduck-lgtm.github.io/claude_class/polygon-bridge/

## 확정된 사용자 요구
1. 새 장치는 매치3 게임의 새 타일처럼 **처음 한 번 설명**하고 이후에는 별도 설명 없이 자연스럽게 재등장.
2. 평행·직각·정다각형·대각선 장치마다 **고유 시각 요소와 체결/가동 애니메이션**.
3. 초기 화면에 수학 조건을 미리 노출해 발견의 의미를 없애지 않는다. (최초 학습 장치 안내는 예외)
4. **공이 움직이는 도중에도 즉시 중단·수정·재도전** 가능.
5. 최소 정보로 화면을 구성하며, 태블릿 가로 화면 사용과 링크 접속을 기본으로 함.
6. **교육적 정합성**: 도형을 단순히 교체해도 물리 결과가 같다면 충분한 학습 게임이 아니므로 기하학적 조건 검증이 게임 기계에 실질적으로 작용해야 함.

## 장치 사전

| 코드 | 장치 | 수학적 조건 | 고유 반응 |
| --- | --- | --- | --- |
| P | 평행 잠금장치 ∥ | 사각형의 마주 보는 두 변이 평행 | 양쪽 기계팔 체결, 초록 전류 |
| R | 직각 연결기 ∟ | 한 꼭짓점에서 만나는 두 변이 직각 | ㄱ자 힌지가 정확히 맞물림 |
| E | 정삼각형 열쇠 △ | 세 변의 길이가 같음 | 금빛 삼각 열쇠 활성화 |
| D | 대각선 발전기 ✧ | 오각형의 서로 이웃하지 않은 꼭짓점을 잇는 고유 대각선 5개 | 에너지 선 충전 및 가동 |

장치 작동 조건은 **가상 게임 규칙**이다. 실제 다리가 반드시 특정 도형이어야 안전하다고 가르치면 안 된다.

## 챕터 1 — 구현된 스테이지 8개
| 단계 | 표면 미션 | 모듈 | 학습 역할 |
| --- | --- | --- | --- |
| 1 | 첫 번째 잠금 | P | 최초 장치 소개 |
| 2 | 멀어진 고리 | P | 설명 없는 재등장 |
| 3 | 꺾인 연결기 | R | 최초 장치 소개 |
| 4 | 두 단계 잠금 | P → R | 순차 복합 |
| 5 | 빛나는 열쇠 | E | 최초 장치 소개 |
| 6 | 교차 관문 | P → E | 순차 복합 |
| 7 | 별빛 발전기 | D | 최초 장치 소개 |
| 8 | 마지막 동력실 | P → R → E → D | 종합 복합 + 챕터 확인 |

**중요**: 현재 복합 스테이지는 장치를 순서대로 해결한 뒤 다음 모듈로 바꾸는 체크포인트 방식이다. 한 장면에서 여러 도형을 동시에 조작하는 진정한 복합 퍼즐은 아직 구현하지 않았다.

## 챕터 2 — 신규 스테이지 9~16

| 단계 | 표면 미션 | 실제 메커니즘 | 학습 목적 |
| --- | --- | --- | --- |
| 9 | 두 개의 표시등 | 동일한 사각형에서 평행+직각 동시 조건 | 두 성질을 함께 만족 |
| 10 | 돌아온 열쇠 | 정삼각형 → 오각형 대각선 | 기존 개념 재사용 |
| 11 | 마름모 톱니 | 네 변 길이가 같은 마름모 | 새 장치 첫 학습 |
| 12 | 연결된 톱니 | 평행 → 마름모 | 기존·신규 조합 |
| 13 | 정사각형 방패 | 네 변 같음 + 네 각 직각 | 새 장치 첫 학습 |
| 14 | 회전하는 방패 | 정사각형 → 직각 연결기 | 성질 재적용 |
| 15 | 혼합 회로 | 평행+직각(동시) → 정삼각형 → 마름모 | 동시 및 순차 조합 |
| 16 | 챕터 2 동력실 | 평행+직각(동시) → 마름모 → 정사각형 → 대각선 | 종합 퍼즐, 챕터 2 확인 |

### 신규 장치 세부 규칙

- **평행+직각 복합 잠금 (기호 ∥∟)**: 동일한 사각형의 윗변/아랫변 평행과 왼쪽 위 꼭짓점의 직각을 **동시에** 판정. 한쪽 조건만 만족하면 한쪽 표시등만 초록색이며 물리 다리는 열리지 않음.
- **마름모 톱니 (◇)**: 윗변의 두 꼭짓점을 고정하고, 한 꼭짓점을 조정하면 네 번째 점이 자동으로 대응하여 평행사변형을 구성. 인접한 변의 길이까지 같아지면 네 변이 같다는 성질을 충족. 정사각형도 마름모의 범주에 포함한다.
- **정사각형 방패 (□)**: 동일한 생성 방식으로 평행사변형을 만든 뒤, 인접한 변의 길이가 같고 한 각이 직각일 때 작동. 사각형의 다른 각도 직각이 되어 정사각형을 구성.
- 새 장치만 처음 한 번 설명. 반복 시 기호·색상·작동 애니메이션만 표시.
- 새 장치의 조건은 교과 개념과 별도로 판정하며, 물리 시뮬레이션에서 다리 고정 여부를 결정.
- 챕터 2 마지막에 정사각형·마름모·복합 조건 관련 4문항 확인. 게임 중 매 스테이지 정답 문제는 생략.

**현재 복합 방식의 경계:** 9, 15, 16단계에서 **한 도형에 두 조건을 동시에 만족시키는 퍼즐**이 실제 구현되었다. 여러 독립 도형을 동일 화면에 놓고 동시에 조작하는 방식은 아직 미구현이다. 기타 복합 스테이지는 장치를 하나씩 켜는 순차 체크포인트 방식이다.

## 화면 구성
- 상단: 1~16 번호 네비게이션(8개씩 두 줄), 현재 미션 한 줄.
- 게임 화면: 공·도형·조작 점·장치 애니메이션, 복합 단계에서 현재/완료 장치 토큰.
- 하단: 처음부터, 단서, 출발, 중단·수정, 즉시 재도전. 사용 가능하지 않은 조작은 숨김.
- 장치 첫 등장: 기호와 짧은 조건 소개, [직접 해보기]. localStorage로 기기별 최초 1회 노출(기존 sessionStorage 기록도 읽어 이관).
- 구슬 도착: 다음 단계로 자연스럽게 연결. 매 단계 퀴즈 제거. 8·16단계에서 챕터별 4개 개념 확인.
- 완료 기록: 브라우저 localStorage (계정·중앙 수집 없음).

## 구현 메모
- HTML/CSS/JS 단일 정적 페이지, GitHub Pages 배포.
- Canvas 내부 좌표 1100×560, 공 반지름 16, 중력 1180, 초깃값 수평속도 255, 실험 최대 약 7.8초.
- 평행 판정: 두 변 벡터의 정규화 외적 절댓값 < 0.0025.
- 직각 판정: 두 변 벡터의 정규화 내적 절댓값 < 0.0035.
- 정삼각형: 각 변 길이 차 < 1.8 게임 좌표 단위.
- 오각형 대각선: 서로 이웃하지 않은 두 점의 고유 선분 5개, 중복 제외.
- 물리 판정(구슬 이동)과 수학 판정(장치 활성화)은 분리.
- 상태: 편집, 실험, 실패, 도착. 공이 멈추기 전에도 중단·재도전 가능.

## 현재 검수
- 16단계 모두 도형 조건을 실제로 충족한 뒤 구슬 도착까지 이어지는 모의 실행 검사 통과. 평행+직각 동시 조건에서 한쪽만 충족해도 실패하는 것 확인.
- 진행 중 중단·즉시 재도전 및 8→16단계 완료 기록 이관: 모의 실행 검사 통과.
- 실제 교실 태블릿 24대의 터치 조작·가독성·동시 접속: 추가 확인 필요.

## 다음 개발 우선순위
- **P0** 실물 Android 태블릿 가로 화면에서 드래그, 버튼 크기, 텍스트 겹침 검수.
- **P0** 새로운 장치의 튜토리얼을 정적인 글보다 **짧은 장치 동작 시범 애니메이션**으로 강화.
- **P1** 한 도형 내 두 조건을 넘어, **서로 독립된 여러 도형을 같은 장면에서 동시에 조작**하는 복합 퍼즐.
- **P1** 마지막의 구슬 도착 완료와 학습 확인 문제 완료를 분리해서 기록.
- **P1** 우연한 드래그보다 도형 성질 이해가 성공에 더 크게 작용하도록 난이도 및 판정 피드백 개선.
- **P2** 필요한 경우 식별정보 없는 학습 진단 지표 추가.
