## 구현과 기준선
기준선에서 Node 검사 중 06의 가벼운 시험이 실패했다. 기본 레일이 연결되지 않은 상태에서 시험을 시작해 작업자가 첫 틈에 떨어졌다. 06은 레일을 연결한 상태에서 시작하고 학생이 다시 조정할 수 있다. 작업자 시험 뒤 한 번 눌러 같은 설계로 화물차를 보낼 수 있다. 화물차의 앞뒤 바퀴와 작업자의 발이 실제 상판을 지지점으로 사용한다. 05의 기존 잔상·경첩 드래그·두 번 터치·두 대각선 보강을 유지했다.

## 2026-11-23 최종 조작성·접속 교정 검수

### 10단계 차단문의 정확한 90° 스냅

- **자동 정렬 진입:** 문 정지 각도가 90° 기준 ±4° 이내면 `design.gate`를 **실제 90°**로 수정한다.
- **정렬 유지 및 해제:** 정렬 중 ±6° 미만이면 유지, 6° 이상 벗어나면 원래 손가락 입력 각도를 따라간다.
- **보이는 효과:** 장치 확대 화면의 녹색 가이드와 `90° ✓` 표시가 실제 수정된 문 좌표를 사용한다. 슬라이더의 손잡이는 조작 종료 시 보정된 값으로 이동한다.
- **물리적 결과:** 86·87·90·92·94°에서는 정렬된 문이 좁은 수납실에 들어가 통과한다. 새 입력 94.1°/95° 이상은 별도의 성공 플래그가 아니라 문 끝과 수납실의 실제 충돌로 과수납 정지한다. 85°에서는 덜 수납되어 작업자가 문에 막힌다.
- **범위 오해 주의:** 이전에 측정한 89.5~90.5°는 보정 전 순수 물리 성공 범위다. 수정 후 학생의 허용 **입력 범위**와 문이 실제 수납되는 기하학적 범위를 구별한다.

### 07·12단계 4절 링크와 도킹

- 연결 막대 보정은 별개 막대의 각도가 아니라 `pose()`가 계산하는 **실제 이동 발판의 기울기**를 측정한다. 플랫폼이 수평과 4° 이내로 가까우면 실제 링크 길이를 100 월드 단위로 정렬한다. 6° 해제 히스테리시스를 적용한다.
- **12단계 정지 위치:** 목표 113°에서 ±4° 이내면 `design.stopAngle=113`으로 수정한다. 따라서 109~117° 근접 조작은 실제 정지 위치와 연결판 모두 목표 좌표를 사용한다. 새로운 입력 118° 및 125°는 조정되지 않으며 정상적인 미도킹 실패가 남는다.
- `connector()`가 제공하는 연결판 선분은 **동일한 `tracks()` 배열에서 그리기와 발바닥 접지에 공용**한다. 수평 간격 0~10, 높이 차 0~8 월드 단위에서만 실제 보이는 연결판을 생성한다.
- 보이는 연결판 위의 보행은 해당 선분에 한해서 최대 8 월드 단위까지 높이 보정을 허용한다. 다른 경로에 보이지 않는 충돌면이나 순간이동을 추가하지 않는다.
- 화면에는 `막대 정렬 ✓`과 `정지 위치 정렬 ✓`을 **별도 표시**하여 막대만 정렬한 상태를 도킹 완료라고 오인하지 않도록 한다.
