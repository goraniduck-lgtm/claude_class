# 물리 기반 운송 퍼즐 — 05단계 보강교 구현 기록 v2.2

작성일: 2026-11-23 · 상위 제작 기준: 사용자 제공 `다각형_다리_작전_물리퍼즐_통합제작명세_v2.1.md`

> 이 기록은 `polygon-bridge/transport.html`의 물리 퍼즐 05·06·08단계에만 적용된다. 같은 저장소의 24단계 조건형 게임 `index.html`과 `DESIGN_SPEC.md`는 변경하지 않는다.

## 목표와 조작

- 05 **흔들리는 다리**: 두 아래쪽 고정 경첩과 두 위쪽 자유 경첩을 연결하는 4개의 고정 길이 막대로 사각형 프레임을 구성한다. 옆바람 때문에 막대 길이를 유지하면서 사각형이 전단 변형한다.
- 학생은 A/B/C/D 경첩 두 곳을 선택해 보강 막대 한 개를 직접 설치한다. 두 번째 선택 전에는 시작 경첩과 점선 미리보기를 표시한다.
- 보강 막대는 **다섯 번째 길이 제약**이다. 기존 변 위에 겹친 막대는 새로운 제약을 주지 않아 실패하며, 두 대각선 중 어느 쪽으로 설치해도 자유도가 줄어 안정된다.
- 실제 움직이는 상판 좌표를 작업자와 화물차의 보행·접촉 계산에 사용한다. `hasDiagonal`을 검사하여 자동으로 통과시키는 코드는 사용하지 않는다.

## 물리·시각적 피드백

- 옆바람 화살표(05), 보강 전 초기 형태의 회색 점선, 변형되는 실제 막대, 사람·화물차의 하중 방향 화살표를 표시한다.
- `frameShear` / `peakShear`는 아래쪽 고정 경첩에 대한 위쪽 경첩의 실제 수평 변위를 측정한다.
- '다리 흔들림' 막대는 위 물리 값으로만 갱신한다. 보강 실패 시 변형된 상판으로 인해 작업자가 떨어지며, 잠시 관찰 후 원인을 설명하는 어린이용 메시지를 표시한다.
- 작업자의 기준 하중을 05·06·08에서 일관되게 설정한다. 05에서 추가로 흔들리는 이유는 옆바람이며, 06에서 무거운 화물차가 실패하는 이유는 더 큰 하중이다.
- 기본 화면에서 전문 용어 '모터가 멈췄어요'를 없애고, 막대가 움직이지 않는 상황을 쉬운 말로 설명한다.

## 남은 검수 / 다음 작업

- 실제 교실용 Android 태블릿의 조작점 크기, 터치 입력, 그려지는 막대/상판 대비와 애니메이션 속도 검수는 미완료다.
- 06의 하중 차이를 어린이가 시각적으로 더 잘 이해할 수 있도록 보행과 화물차의 눌림·흔들림 연출 개선을 검토한다.
- 08에서는 레일·차단문·프레임·승강교가 연결된 상태에서 화면 연결판과 실제 충돌체가 일치하는지 실기기로 확인한다.
- 후속 09~12단계는 v2.1 제작명세의 설계 후보이며 자동 배포 범위가 아니다. 재사용 구조물의 실제 변형이 새로운 플레이 목표를 만드는지 먼저 검증한다.

**검수 범위의 한계:** 코드·시뮬레이션 기반 검사와 모의 Canvas 호출 결과이지, 실제 24대 태블릿 동시 사용이나 학생 이해도 검수가 완료됐다는 의미는 아니다.
