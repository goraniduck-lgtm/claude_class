## 이미 구현되어 있었던 물리 모델

물리 챕터의 05단계에는 기존부터 네 경첩/네 막대의 거리 제약, 바닥 두 지지점, 작업자 하중, 추가 보강재의 **길이 제약**, 프레임 상판과 작업자의 실제 접지 계산이 있었다. 구조를 처음부터 새로 만든 것이 아니라 **수학적 인과 관계가 있는 기존 구현을 보존·검수**하고 학생 조작과 반응을 개선했다.

막대의 끝점 (p_a,p_b)와 고정 길이 (L_{ab})에 대해 거리 제약 `|p_a - p_b| = L_ab`를 반복적으로 보정한다. 사각형 경첩 프레임의 기존 변을 중복 보강하면 새로운 제약이 생기지 않으며, 대각선을 고정하면 구조의 자유도가 줄어든다. 렌더링하는 상판 선분과 작업자 접지 판정은 물리 계산에 사용되는 프레임 노드 좌표를 공유한다.

## 이번 구현

1. **직접 잇기:** 노란 경첩에서 다른 경첩까지 터치·마우스로 드래그해 보강 막대를 연결. 노란 점을 두 번 터치하는 방식과 A/B/C/D 버튼 조작도 제공.
2. **임시 선분:** 드래그 중 점선 보강 막대와 선택된 경첩 강조. 설치 후 실제 프레임에 노란 막대 표시. 대각선 연결 시 두 삼각형 영역을 옅게 구분.
3. **학생용 피드백:** 첫 경첩 선택, 막대 설치, 기존 변을 따라 중복 설치, 보강 성공과 실패에 대해 간단하고 원인 중심인 한국어 안내. 첫 시도에 "대각선이 정답"을 선제적으로 공개하지 않음.
4. **관찰 시간:** 보강 실패 시 사각형의 변형과 작업자 추락/정지 결과를 기존보다 오래(약 1.25초) 볼 수 있도록 한 다음 설계 상태로 복귀.
5. **터치 정확도:** 경첩의 최소 히트 영역은 반지름 22 CSS px 상당 이상, 실제 캔버스의 화면 크기에 맞춰 입력 좌표 변환.
6. **회귀 보호:** 기존 레일 스냅, 차단문, 승강교 코드와 물리 챕터 저장 키를 유지.

## 현재 물리 모델의 범위·주의

- 2차원 점-막대 거리 제약 모형이다. 현실 교량 구조의 재료 강도, 탄성 변형, 안전율, 정확한 힘 분포까지 계산하는 구조해석 도구가 아니다.
- 05/06/08은 서로 다른 하중 파라미터를 적용해 같은 모델의 변형 결과를 확인한다. '무거우면 무조건 실패' 같은 정답 플래그를 사용하지 않는다.
- 경첩 두 곳을 연결할 때 부품은 초기 프레임 기준의 길이로 고정된다. 막대의 역할은 실제 제약에 반영되며 성공 애니메이션을 조건문으로 대체하지 않는다.
- 기존 01~08단계 및 조건형 24단계의 학습 기록은 삭제하거나 변경하지 않는다.

## 다음 제작·검수 순서

1. **05 실제 태블릿 검수:** 학생이 경첩 2개를 잇는 조작을 직관적으로 이해하는지, 두 번 터치/드래그 오작동이 없는지 24대 기기 환경에서 확인.
2. **06 학습 차별화:** 먼저 작업자, 다음에 화물차를 시험하도록 관찰 시점과 버튼 흐름을 정리. 보강 전후의 프레임 변화량을 그림으로 비교할 수 있도록 개선.
3. **08 통합 검수:** 레일·차단문·보강교·승강교가 하나의 운송 경로 안에서 각각 실패 원인을 실제로 만드는지 테스트.
4. **후속 후보 09~12 재검토:** 기존 물리 모듈로 해결할 수 있는 실제 장애와 새로운 실패 유형이 있는 경우에만 제작 확정.

**완료 승인 질문:** '대각선 막대를 설치하면 성공'이 아니라, '막대를 추가해 사각형의 모양이 덜 변하므로 작업자가 건널 수 있다'는 관계가 화면에 보이는가? 이 질문은 실제 학생 플레이 관찰로 최종 승인한다.
